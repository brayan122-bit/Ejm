Cierre mensual de asistencias

Este proceso genera la fila de cobro del mes para todas las suscripciones Activas en la tabla de meses. La columna aparecerá automáticamente en el consolidado y descargas.

Ejemplo: 2026-10 para octubre de 2026 (oct-26).

Reglas del cierre:
  • Se calcula con el VALOR CON IVA de cada suscripción activa.
  • Suscripciones inactivadas antes de este mes NO generan cobro.
  • Si el mes ya fue cerrado previamente, este proceso actualiza los valores sin duplicar filas.
